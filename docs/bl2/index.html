BL2 Save Editor

How to use this with a PS4 save
  1. PS4 saves are encrypted. Copy your save to a USB stick and decrypt it with a tool such as Save Wizard.
  2. Tap Open save and pick the decrypted Borderlands 2 save file. Nothing is uploaded; everything happens in this browser.
  3. Edit what you want. Weapons show a picture that updates as you change parts.
  4. Tap Download edited save, put it back where it came from (same file name), and re-encrypt / resign it with your save tool before copying it to the PS4.
  5. Keep a backup of the original save. Edited saves can be rejected or break if something unusual is in them.

No save yet? Open the Weapons tab and use Build a weapon or paste a BL2(...) code to play with the preview.
